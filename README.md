# 🏐 KAALSK - Kırklareli Atatürk Anadolu Lisesi Spor Kulübü

Bu depo, **Kırklareli Atatürk Anadolu Lisesi Spor Kulübü (KAALSK)** resmi web sitesinin kaynak kodlarını içermektedir. Proje; kulübün tarihçesini, teknik kadrosunu, etkinliklerini ve duyurularını sporseverlere ulaştırmak amacıyla geliştirilmiştir.

🌐 **Canlı Siteyi Ziyaret Et:** [www.kaalsk.com](http://www.kaalsk.com)

---

## ✨ Öne Çıkan Özellikler

* **Dinamik Duyuru Sistemi:** Kulüp faaliyetleri ve yeni dönem voleybol kayıtları hakkında güncel bilgiler.
* **Teknik Kadro Tanıtımı:** Profesyonel antrenörlerin ve teknik sorumluların detaylı özgeçmişleri.
* **Etkinlik & Maç Takvimi:** Dostluk maçları, turnuvalar ve seçme bilgilerinin takibi.
* **Multimedya Galerisi:** Antrenman ve maç anlarından görsel içerikler.
* **Responsive Tasarım:** Tüm mobil, tablet ve masaüstü cihazlarla tam uyumlu kullanıcı arayüzü.

---

## 🛠 Kullanılan Teknolojiler

Proje modern web standartları kullanılarak inşa edilmiştir:

* **Frontend:** HTML5, CSS3, JavaScript
* **Stil:** Custom CSS (Flexbox & Grid)
* **İletişim:** Entegre iletişim formu ve sosyal medya entegrasyonu
